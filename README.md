## Yōkoso, tabibitoyo

![Genshin Impact Databoard preview](https://github.com/user-attachments/assets/cd304b50-a70a-401e-a99e-df498ed27d0b)

This project is a side project for storing and organizing Genshin Impact character, artifact, and party data. It helps players quickly review game information without relying on multiple interfaces.

### Team Builder and Synergy Checker

The Team Builder lets you assemble a 4-character party and immediately evaluate how the lineup may perform.

![Team Builder and Synergy Checker](https://github.com/user-attachments/assets/09f6c14b-6134-4dd4-b5c3-32d3a7d2130d)

The builder includes:

* Four configurable party slots
* Character search and element or role filters
* Automatic character de-duplication across the party
* Saved party slots through browser local storage
* Sample squad and clear party actions
* Links to each selected character kit
* Elemental Resonance checks for 2, 3, 4 matching elements and rainbow parties
* Reaction coverage for Vaporize, Melt, Overloaded, Frozen, Swirl, Crystallize, Dendro reactions, and more
* On-field DPS, sub-DPS, support, and sustain role counts
* Synergy highlights and roster warnings

Select a party slot, choose a character from the roster, and the synergy dashboard updates automatically.

### Additional features

* Navigate character skill previews with the left and right arrow keys
* Hover over skill icons to read a short tooltip
* Load skill and burst media externally, except for essential interface icons
* Save the active 4-character team in browser local storage

> [!NOTE]
> This project is still in development. Additional characters, regions, artifact sets, and team-building rules may be added.
